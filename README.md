## 📝 Descrição
O **Ateliê Açucarado** é um website institucional desenvolvido para uma doceria artesanal. O projeto foca em uma identidade visual elegante, utilizando tons de chocolate e lavanda, com o objetivo de transmitir a qualidade e o carinho dedicados à produção de doces gourmet e experiências sensoriais.

## 🚀 Funcionalidades
* **Design Responsivo:** Interface adaptável para dispositivos móveis e desktops.
* **Navegação "Smooth Scroll":** Rolagem suave entre as seções da página para uma melhor experiência do usuário.
* **Identidade Visual Customizada:** Integração de cores exclusivas via Tailwind CSS.
* **Integração Social:** Links rápidos para atendimento via WhatsApp, redes sociais e apps de entrega (iFood/99 Food).
* **Seções Estratégicas:** Início (Hero), Sobre, Serviços, Cardápio e Contato.

## 🛠️ Tecnologias Utilizadas
* **Frontend:** HTML5 semântico.
* **Estilização:** [Tailwind CSS](https://tailwindcss.com/) (configurado via CDN e JS).
* **Ícones:** [Bootstrap Icons](https://icons.getbootstrap.com/).
* **Lógica de Interação:** Vanilla JavaScript (ES6+).

## 🔧 Como Executar
O projeto é puramente frontend (estático), não exigindo compiladores ou servidores complexos.

**Clone o repositório:**

```bash
git clone [https://github.com/WTC13/atelie_acucarado/tree/main](https://github.com/WTC13/atelie_acucarado/tree/main)
```

**Abra o arquivo principal:**
Navegue até a pasta raiz e abra o arquivo `index.html` em seu navegador de preferência.
